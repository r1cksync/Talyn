# Talyn visual design

Adapted with the owner's authorization from the private `r1cksync/nightshift-record-label-site-remix` repository. The reference checkout stays outside version control. Its unrelated backend, tracking, artist content and remote media were not incorporated.

The landing page carries the reference's repeated outlined typography, dark charcoal surfaces, acid yellow feature panels, thin dividers, graphic process cards and expandable rows. The copy and graphics describe Talyn's interview workflow. Calls to action open the working workspace.

The same tokens cover account creation, manager navigation, candidate preparation, live captions, recording controls, plans, reports, notifications and settings. Display headings use Anton; forms and reading text use Archivo; labels use IBM Plex Mono. All font files are served locally with the application.

Reduced-motion preferences disable scroll movement. A visible motion control remains available. Layouts were checked at 1440px and 390px. Browser tests exercise landing navigation, expandable principles, the mobile sign-in view and the complete synthetic manager/candidate workflow. Screenshots are generated in ignored `frontend/test-results/`.
